# Emperor Time Server Caboom update

This patch updates `GodCoreMod.java` with a 3-second Caboom charge-up and an instant kill for other players within 100 blocks of the aimed target. The caster is spared. It also updates the project README with these details.

Upload the `src` folder and this README to the root of the existing `weapon-server-side` repository, preserving the folder structure, then commit the changes. GitHub Actions builds the JAR.

The TikTok effect uses custom visuals; this mod approximates it with vanilla Minecraft particles and blocks.
